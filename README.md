# HUBSUS360
HUBSUS360 é um projeto acadêmico da FIAP desenvolvido para o Challenge da Oracle. O painel inteligente integra dados do SIH e CNES para monitorar internações, ICSAP, custos, perfil dos pacientes, fluxo entre municípios e capacidade hospitalar, gerando indicadores e alertas para apoiar a gestão da saúde pública.
