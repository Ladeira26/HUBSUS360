# DDL - Estrutura do banco

Esta pasta contém o script DDL do modelo relacional do HUBSUS360.

O script cria as tabelas, chaves primárias e estrangeiras, índices e regras de integridade utilizadas para organizar diagnósticos, grupos ICSAP, municípios, estabelecimentos, procedimentos, perfis de internação e indicadores assistenciais.

Para reproduzir a estrutura, execute o arquivo `01_ddl_experimental.sql` em um schema Oracle vazio.
