# DML - Carga de dados

Esta pasta contém o script DML com dados de referência e uma amostra técnica do HUBSUS360.

Para reproduzir a carga:

1. Execute primeiro o DDL em `../ddl/01_ddl_experimental.sql`.
2. Execute `02_dml_amostra.sql` usando Executar como Script (F5) no Oracle SQL Developer.
3. Consulte as tabelas para conferir os relacionamentos e os registros inseridos.

A carga é demonstrativa e não representa a base completa do SIH/SUS. Não há dados pessoais ou números de matrícula neste material.
