# SQL - Banco de dados

Esta pasta reúne os scripts SQL utilizados para estruturar e testar o modelo relacional do HUBSUS360 no Oracle SQL Developer.

Os arquivos foram separados por responsabilidade:

- `ddl/`: criação das tabelas, chaves, índices e regras de integridade;
- `dml/`: inserção dos dados de referência e da amostra técnica.

A carga disponível é uma amostra para validação da estrutura e não representa a base completa do SIH/SUS.
