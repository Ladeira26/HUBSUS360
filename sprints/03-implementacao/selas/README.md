# Ética, governança e segurança

Esta frente trata dos princípios e controles necessários para uma solução de dados em saúde, incluindo ética, LGPD, Zero Trust, auditoria, human-in-the-loop, guardrails do Select AI e COBIT 2019.

O objetivo é garantir que o uso dos dados seja responsável, rastreável e adequado ao contexto da solução.
